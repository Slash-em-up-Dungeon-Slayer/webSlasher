# План поэтапной разработки (кратко)

- **Этап 0** — установка ПО (Unity 6.3 LTS + WebGL Build Support, .NET 8, Docker), домен и хостинг
- **Этап 1** — прототип камеры (pseudo-3D), input-абстракция (мышь+тач), система способностей (IAbility)
- **Этап 2** — каркас репозитория (этот архив)
- **Этап 3** — offline вертикальный срез геймплея
- **Этап 4** — backend-скелет, PostgreSQL, авторизация (этот архив покрывает базовую часть)
- **Этап 5** — серверное время как источник истины, анти-чит
- **Этап 6** — мета-прогрессия персонажа
- **Этап 7** — магазин через Stripe/PayPal, серверная валидация оплаты по webhook
- **Этап 8** — rewarded-ads для веба
- **Этап 9** — Docker/Kubernetes для доставки (см. `k8s/`)
- **Этап 10** — WebGL-специфичный чеклист (сжатие, COOP/COEP, автоплей звука)
- **Этап 11** — кроссбраузерное QA и запуск
